# Muhammad Shahzaib — Portfolio Website

A responsive, single-page portfolio website with a light/dark theme switcher, project filters, mobile navigation, and CV links.

## Included
- `index.html` — page content and project cards
- `style.css` — responsive layout and both color themes
- `script.js` — theme switcher, mobile menu, project filters, and scroll effects
- `assets/Shahzaib-CV.pdf` — CV supplied for this portfolio

## Preview locally
Open `index.html` in a browser. For best results, use a local development server (for example, VS Code Live Server).

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com/
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io`.
3. Upload all files and folders from this project. Keep `index.html` at the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Your site address will be `https://YOUR-USERNAME.github.io/`.

A custom domain is optional and must be purchased separately. GitHub Pages is free for public repositories on GitHub Free.
